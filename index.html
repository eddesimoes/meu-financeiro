Dados e segurança

Ligação bancária — estado real

Não ligada

A sincronização automática ainda não está configurada. Não introduzas credenciais do Revolut aqui. A API de Open Banking do Revolut destina-se a prestadores terceiros regulados; o acesso de produção requer autorização/certificados. Para um projeto pessoal com orçamento €0, a alternativa imediata é importar um extrato CSV.

A Tink disponibiliza sandbox gratuita com dados de teste, mas indica que o acesso de produção exige um plano comercial. Confirma cobertura e preço antes de assumir qualquer custo.

Importar CSV do banco

Formato recomendado: date,description,amount,type,category. Datas AAAA-MM-DD ou DD/MM/AAAA; tipo income/expense. Confirma os movimentos importados.

Cópia de segurança

Os dados ficam neste navegador/dispositivo. Exporta uma cópia regularmente. A app não envia os teus dados para servidores.

Instalação no Android

Quando estiver alojada num endereço HTTPS, abre-a no Chrome e escolhe “Instalar app” ou “Adicionar ao ecrã principal”. O modo offline funciona depois de o service worker ser instalado.
